## Overview

Developed a full-featured art e-commerce platform with role-based access for buyers, sellers, and administrators. The system includes artwork listing and approval workflows, cart-to-checkout order processing, and review, messaging, and notification functionality.

## Tools

Django, SQLite, Bootstrap, HTML, CSS, JavaScript
